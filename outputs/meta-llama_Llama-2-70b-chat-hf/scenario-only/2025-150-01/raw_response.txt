Intent:
The MQTT Payload Ontology models automated process data captured and transmitted via MQTT packets in the context of the EKI project. It provides a vocabulary for describing the various payload formats and encodings used in MQTT message protocols.

Covered requirements:

* Modeling automated process data captured and transmitted via MQTT packets.
* Describing the various payload formats and encodings used in MQTT message protocols.
* Enabling seamless alignment between observation and actuation process descriptions with transport semantics.
