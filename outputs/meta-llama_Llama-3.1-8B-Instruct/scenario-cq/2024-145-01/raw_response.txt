### Ontology Design Pattern (ODP) in Turtle Syntax

```turtle
@prefix owl:  <http://www.w3.org/2002/07/owl#>.
@prefix rdf:  <http://www.w3.org/1999/02/22-rdf-syntax-ns#>.
@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#>.
@prefix xsd:  <http://www.w3.org/2001/XMLSchema#>.
@prefix :     <http://example.org/odp#>.

:Ontology a owl:Ontology ;
  rdfs:label "Court and Bad Check Regulations Ontology" ;
  rdfs:comment "Ontology for court hierarchies and bad check regulations.".

:State a rdfs:Class ;
  rdfs:label "State" ;
  rdfs:comment "A state in the United States or India.".

:DistrictCourt a rdfs:Class ;
  rdfs:label "District Court" ;
  rdfs:comment "A district court in a state.".

:State a :hasDistrictCourt ;
  rdfs:label "has District Court" ;
  rdfs:comment "A state has one or more district courts.".

:DistrictCourt a :locatedInState ;
  rdfs:label "located in state" ;
  rdfs:comment "A district court is located in a state.".

  rdfs:label "has authority over" ;
  rdfs:comment "A state has authority over one or more district courts.".

:DistrictCourt a :hasAuthorityOver ;
  rdfs:label "has authority over" ;
  rdfs:comment "A district court has authority over one or more lower courts.".

:Check a rdfs:Class ;

:Check a :hasTransactionStatus ;

  rdfs:comment "A check has a transaction status.".

:CheckType a rdfs:Class ;
  rdfs:label "Check Type" ;

:BadCheck a :hasCheckType ;
