### Turtle Ontology

```turtle
@prefix owl:  <http://www.w3.org/2002/07/owl#>.
@prefix rdf:  <http://www.w3.org/1999/02/22-rdf-syntax-ns#>.
@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#>.
@prefix xsd:  <http://www.w3.org/2001/XMLSchema#>.
@prefix :     <http://example.org/odp#>.

:Ontology a owl:Ontology ;
  rdfs:label "Authorship and Pseudonyms" ;
  rdfs:comment "An ontology for modeling authorship and pseudonyms".

:Author a rdfs:Class ;
  rdfs:label "Author" ;
  rdfs:comment "A person who writes books".

:Pseudonym a rdfs:Class ;
  rdfs:label "Pseudonym" ;
  rdfs:comment "A name used by an author to publish under".

:Book a rdfs:Class ;
  rdfs:label "Book" ;
  rdfs:comment "A written work".

:Published a rdf:Property ;
  rdfs:label "published" ;
  rdfs:comment "The act of publishing a book" ;
  rdfs:domain :Author ;
  rdfs:range :Book.

:UsesPseudonym a rdf:Property ;
  rdfs:label "uses pseudonym" ;
  rdfs:comment "An author uses a pseudonym to publish" ;
  rdfs:domain :Author ;
  rdfs:range :Pseudonym.

:Title a rdf:Property ;
  rdfs:label "title" ;
  rdfs:comment "The title of a book" ;
  rdfs:domain :Book ;
  rdfs:range xsd:string.

:Authorship a rdf:Property ;
  rdfs:label "authorship" ;
  rdfs:comment "The relationship between an author and a book" ;
  rdfs:domain :Book ;
  rdfs:range :Author.

:PseudonymUsed a rdf:Property ;
  rdfs:label "pseudonym used" ;
  rdfs:comment "The pseudonym used by an author" ;
  rdfs:domain :Author ;
  rdfs:range :Pseudonym.

:C. S. Lewis a :Author ;
  rdfs:label "C. S. Lewis".

:CSLewis a :Author ;
  rdfs:label "C. S. Lewis" ;
  owl:sameAs :C. S. Lewis.

:CSLewisUsesPseudonym :Pseudonym1 ;
  a :Pseudonym ;
  rdfs:label "Pseudonym1".

:CSLewisPublishedBook :Book1 ;
  a :Book ;
  :Title "Spirit in Bondage" ;
  :Authorship :C. S. Lewis ;
  :PseudonymUsed :Pseudonym1.
```

### Scenario-requirement-to-axiom mapping

1. An author adopting different names to publish books: 
   - Axioms: `:Author a rdfs:Class ;`, `:Pseudonym a rdfs:Class ;`, `:UsesPseudonym a rdf:Property ;`
2. Name changes (e.g., after marriage): 
   - Axioms: `:CSLewisUsesPseudonym :Pseudonym1 ;`, `:Pseudonym1 a :Pseudonym ;`

### CQ-to-axiom mapping

1. Under what pseudonym did the author C. S. Lewis publish a collection of poems, Spirit in Bondage?
   - Classes: `:Author`, `:Pseudonym`, `:Book`
   - Properties: `:UsesPseudonym`, `:PseudonymUsed`, `:Authorship`, `:Title`
2. What alternative did C. S. Lewis use to assume the role of a book writer?
   - Classes: `:Author`, `:Pseudonym`
   - Properties: `:UsesPseudonym`
3. Show the trajectories of rivers which cross national parks? 
   - This competency question is not supported by the ontology, as it is unrelated to the scenario of authorship and pseudonyms.

### Intentionally excluded concepts

- Rivers and national parks: These concepts are not relevant to the scenario of authorship and pseudonyms, and therefore are not included in the ontology.
- Trajectories of rivers: This concept is also not relevant to the scenario and is not included in the ontology.
- Marriage: While name changes after marriage are mentioned in the scenario, the ontology does not explicitly model marriage as a concept. However, it does model the use of pseudonyms, which can be related to name changes after marriage.
