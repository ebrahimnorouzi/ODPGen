```turtle
@prefix owl:  <http://www.w3.org/2002/07/owl#>.
@prefix rdf:  <http://www.w3.org/1999/02/22-rdf-syntax-ns#>.
@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#>.
@prefix xsd:  <http://www.w3.org/2001/XMLSchema#>.
@prefix :     <http://example.org/odp#>.

:Ontology a owl:Ontology ;
  rdfs:label "Author Name Changes Ontology" ;
  rdfs:comment "An ontology to model author name changes.".

:Author a owl:Class ;
  rdfs:label "Author" ;
  rdfs:comment "An individual who writes books.".

:Name a owl:Class ;
  rdfs:label "Name" ;
  rdfs:comment "A name adopted by an author.".

:NameChange a owl:Class ;
  rdfs:label "Name Change" ;
  rdfs:comment "An event where an author changes their name.".

:AuthorName a owl:ObjectProperty ;
  rdfs:label "Author Name" ;
  rdfs:comment "The name adopted by an author." ;
  domain :Author ;
  range :Name.

:NameChangeDate a owl:DatatypeProperty ;
  rdfs:label "Name Change Date" ;
  rdfs:comment "The date when the name change occurred." ;
  domain :NameChange ;
  range xsd:date.

:PreviousName a owl:ObjectProperty ;
  rdfs:label "Previous Name" ;
  rdfs:comment "The name adopted by an author before the name change." ;
  domain :NameChange ;
  range :Name ;
  inverseProperty :NextName.

:NextName a owl:ObjectProperty ;
  rdfs:label "Next Name" ;
  rdfs:comment "The name adopted by an author after the name change." ;
  domain :NameChange ;
  range :Name ;
  inverseProperty :PreviousName.

:NameChangeReason a owl:ObjectProperty ;
  rdfs:label "Name Change Reason" ;
  rdfs:comment "The reason for the name change." ;
  domain :NameChange ;
  range :xsd:string.
```

**Documentation**

**Intent:** This ontology models the relationships between authors, their adopted names, and the events of name changes.

**Covered requirements:**

* An author adopting different names to publish books
* Name changes (e.g., after marriage)

**Known assumptions and exclusions:**

* The ontology assumes that an author can have multiple names, and a name can be associated with multiple authors.
* The ontology does not model the reasons for name changes in detail; it only provides a property to capture the reason.
* The ontology does not capture the context of name changes (e.g., marriage, divorce, etc.).
* The ontology does not provide a mechanism to track the sequence of name changes for an author.
