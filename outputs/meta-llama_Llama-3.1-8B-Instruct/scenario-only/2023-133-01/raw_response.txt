**Documentation**

**Intent:** This ontology models the sprinkler use case, a well-known example in the CBN literature, to reason about the cause of a slippery pavement.

**Covered requirements:**

* Stay strictly within the scenario scope
* Use clear, self-explanatory class and property names
* Include minimal but sufficient axioms (domain, range, subclass, disjointness where justified)
* Declare every class with `a owl:Class`, every property with `a owl:ObjectProperty`, `a owl:DatatypeProperty`, or `a owl:AnnotationProperty`
* Do NOT create individual instances
* Add rdfs:label and rdfs:comment annotations to every class and property

**Known assumptions and exclusions:**

* The ontology assumes that the sprinkler use case is a well-known example in the CBN literature.
* The ontology excludes concepts not implied by the scenario, such as the physical properties of the pavement or the sprinkler system.
* The ontology does not include individual instances of the classes, only the schema axioms.
