   - Represent a relational database as a first-class schema entity.
   - Represent tables belonging to a database.
   - Represent columns belonging to a table.
   - Represent primary-key relationships in the schema.
   - Represent foreign-key relationships.
   - Define policies for specific agents.
   - Specify high-level ReadAction, ModifyAction, ViewActionScope, and ProcessActionScope.
   - Define policies at table, column, and row levels using conditions.
   - Express prohibited modify actions on a table.
   - Express table-level read prohibitions for processing and viewing.
   - Express conditional row-level read restrictions.
   - Represent SQL queries as semantic graphs.
   - Map SQL statements to their semantic action types.
   - Link SQL statements to the executing agent.
   - Assign operational scopes to SQL clauses.
   - Propagate scope to reference nodes as effectiveActionScope.
   - Link TableRef and ColumnRef in the query to their corresponding schema entities.
   - Infer whether a referenced table or column is Violated or RowTag based on the matching policy, action, and scope.
