1. Turtle ontology:

```turtle
:Ontology a owl:Ontology ;
    rdfs:label "Evaluation Request Ontology" ;
    rdfs:comment "An ontology for modeling evaluation requests on assets, with temporal, spatial, role, and request-capability context.".

:Request a subClassOf owl:NamedIndividual ;
    rdfs:label "Evaluation Request" ;
    rdfs:comment "A formal description of a requested action on a target asset.".

:Action rdf:type owl:ObjectProperty ;
    rdfs:domain :Request ;
    rdfs:range xsd:string ;
    rdfs:label "requestedAction" ;
    rdfs:comment "The action requested on the target asset.".

:Party rdf:type owl:Class ;
    rdfs:label "Party" ;
    rdfs:comment "The party issuing the evaluation request.".

:Employee subClassOf :Party ;
    rdfs:label "Employee" ;
    rdfs:comment "An employee of the organization.".

:TargetAsset rdf:type owl:ObjectProperty ;
    rdfs:domain :Request ;
    rdfs:range owl:Class ;
    rdfs:label "targetAsset" ;
    rdfs:comment "The target asset of the evaluation request.".

:Weekday subClassOf xsd:string ;
    rdfs:label "Weekday" ;
    rdfs:comment "A day of the week.".

:Time rdf:type owl:DatatypeProperty ;
    rdfs:domain :Request ;
    rdfs:range xsd:dateTime ;
    rdfs:label "time" ;
    rdfs:comment "The time the evaluation request was issued.".

:Location rdf:type owl:ObjectProperty ;
    rdfs:domain :Request ;
    rdfs:range xsd:string ;
    rdfs:label "location" ;
    rdfs:comment "The location from which the evaluation request was issued.".

:EU rdf:type owl:Class ;
    rdfs:label "EU" ;
    rdfs:comment "The European Union.".

:FromEU rdf:type owl:ObjectProperty ;
    rdfs:domain :Location ;
    rdfs:range :EU ;
    rdfs:label "fromEU" ;
    rdfs:comment "Indicates whether the location is within the EU.".

:AdditionalContext rdf:type owl:ObjectProperty ;
    rdfs:domain :Request ;
    rdfs:range owl:Class ;
    rdfs:label "additionalContext" ;
    rdfs:comment "Additional contextual information included in the evaluation request.".
```

2. Scenario-requirement-to-axiom mapping:
   - Prioritizing semantic faithfulness to the scenario:
     - `:Request a subClassOf owl:NamedIndividual`: Represents the formal description of a requested action on a target asset.
     - `:Action rdf:type owl:ObjectProperty`: Describes the action requested on the target asset.
     - `:Party rdf:type owl:Class`: Represents the party issuing the evaluation request.
     - `:Employee subClassOf :Party`: Restricts the party to employees.
     - `:TargetAsset rdf:type owl:ObjectProperty`: Represents the target asset of the evaluation request.
     - `:Weekday subClassOf xsd:string`: Represents a day of the week.
     - `:Time rdf:type owl:DatatypeProperty`: Represents the time the evaluation request was issued.
     - `:Location rdf:type owl:ObjectProperty`: Represents the location from which the evaluation request was issued.
     - `:EU rdf:type owl:Class`: Represents the European Union.
     - `:FromEU rdf:type owl:ObjectProperty`: Indicates whether the location is within the EU.
