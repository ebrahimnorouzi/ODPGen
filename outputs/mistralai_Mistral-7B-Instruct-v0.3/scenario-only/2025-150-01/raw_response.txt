```turtle
@prefix owl: <http://www.w3.org/2002/07/owl#>.
@prefix rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#>.
@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#>.
@prefix xsd: <http://www.w3.org/2001/XMLSchema#>.
@prefix : <http://example.org/odp#>.

:Ontology a owl:Ontology ;
  rdfs:label "MQTT Process Data Ontology" ;
  rdfs:comment "A model for automated process data captured and transmitted via MQTT packets in the context of the EKI project.".

# Top-level classes
:Topic a owl:Class ;
  rdfs:label "MQTT Topic" ;
  rdfs:comment "A named destination that allows one-to-many communication channels between publishers and subscribers.".

:Message a owl:Class ;
  rdfs:label "MQTT Message" ;
  rdfs:comment "A unit of data transmitted between publishers and subscribers.".

:Payload a owl:Class ;
  rdfs:label "MQTT Payload" ;
  rdfs:comment "The data content of an MQTT message.".

:Encoding a owl:Class ;
  rdfs:label "MQTT Encoding" ;
  rdfs:comment "The character set or format used to represent the MQTT payload.".

# Object properties
:hasTopic a owl:ObjectProperty ;
  rdfs:domain :Message ;
  rdfs:range :Topic ;
  rdfs:label "Has Topic" ;
  rdfs:comment "The MQTT topic associated with a message.".

:hasPayload a owl:ObjectProperty ;
  rdfs:domain :Message ;
  rdfs:range :Payload ;
  rdfs:label "Has Payload" ;
  rdfs:comment "The data content of a message.".

:hasEncoding a owl:ObjectProperty ;
  rdfs:domain :Payload ;
  rdfs:range :Encoding ;
  rdfs:label "Has Encoding" ;
  rdfs:comment "The character set or format used to represent the payload.".

# Data properties
:payloadFormat a owl:DatatypeProperty ;
  rdfs:domain :Payload ;
  rdfs:range xsd:string ;
  rdfs:label "Payload Format" ;
  rdfs:comment "The format of the payload (e.g., plain text, CSV, JSON).".
```

**Intent:**
This pattern models MQTT topics, messages, payloads, and encodings in the context of the EKI project, enabling seamless alignment between observation and actuation process descriptions with transport semantics.

**Covered requirements:**
- Models MQTT topics, messages, payloads, and encodings.
- Enables alignment between observation and actuation process descriptions with transport semantics.
- Accounts for various payload formats and encodings used in MQTT message protocols.

**Known assumptions and exclusions:**
- This pattern does not model MQTT publishers, subscribers, or QoS levels.
- This pattern does not account for MQTT message headers or properties beyond the payload.
- This pattern does not include individual instances of MQTT topics, messages, payloads, or encodings.
