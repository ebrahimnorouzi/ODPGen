:Ontology a owl:Ontology ;
  rdfs:label "Name Change Scenario" ;
  rdfs:comment "This ontology models authors adopting different names to publish books, including name changes due to marriage.".

# Classes
:Author a owl:Class ;
  rdfs:label "Author" ;
  rdfs:comment "A person who writes books.".

:Name a owl:Class ;
  rdfs:label "Name" ;
  rdfs:comment "A string representing a person's name.".

:MarriedName a owl:Class ;
  rdfs:label "Married Name" ;
  rdfs:comment "A name adopted by an author after marriage.".

:BirthName a owl:Class ;
  rdfs:label "Birth Name" ;
  rdfs:comment "The original name of an author.".

# Object Properties
:hasName a owl:ObjectProperty ;
  rdfs:domain :Author ;
  rdfs:range :Name ;
  rdfs:label "hasName" ;
  rdfs:comment "Relates an author to their name.".

:adoptsName a owl:ObjectProperty ;
  rdfs:domain :Author ;
  rdfs:range :Name ;
  rdfs:label "adoptsName" ;
  rdfs:comment "Relates an author to a name they have adopted.".

:isMarriedNameOf a owl:ObjectProperty ;
  rdfs:domain :Name ;
  rdfs:range :MarriedName ;
  rdfs:inverseOf :adoptsMarriedName ;
  rdfs:label "isMarriedNameOf" ;
  rdfs:comment "Relates a name to the married name it represents.".

:isBirthNameOf a owl:ObjectProperty ;
  rdfs:domain :Name ;
  rdfs:range :BirthName ;
  rdfs:inverseOf :adoptsBirthName ;
  rdfs:label "isBirthNameOf" ;
  rdfs:comment "Relates a name to the birth name it represents.".

# Disjointness
:MarriedName disjointWith :BirthName.

- Include minimal but sufficient axioms (domain, range, subclass, disjointness where justified).
- Declare every class with `a owl:Class`, every property with `a owl:ObjectProperty`, `a owl:DatatypeProperty`, or `a owl:AnnotationProperty`.
- Do NOT create individual instances (e.g. `:SomePerson a :Person`); output schema axioms only.
- Add rdfs:label and rdfs:comment annotations to every class and property.
- Declare a mandatory ontology header: `:Ontology a owl:Ontology ; rdfs:label "..." ; rdfs:comment "...".`

# Known assumptions and exclusions:
- This ontology does not model the process of name changes or the reasons behind them. It only models the relationships between authors and their names.
- This ontology does not handle multiple marriages or name changes after multiple marriages.
- This ontology does not handle the case where an author has the same name before and after marriage.
