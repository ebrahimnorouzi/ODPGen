  rdfs:domain :Vessel ;

  rdfs:domain :Vessel ;

  rdfs:label "Vessel Type" ;

  rdfs:label "Propulsion System" ;

**Intent:**
This pattern models a basic ontology for representing maritime vessels and their propulsion systems in a machine-interpretable way, providing a foundation for interoperability, reuse, and automated reasoning across various maritime data sources.

**Covered requirements:**
- Stay strictly within the scenario scope
- Use clear, self-explanatory class and property names
- Include minimal but sufficient axioms
- Declare every class with `a owl:Class`, every property with `a owl:ObjectProperty`, `a owl:DatatypeProperty`, or `a owl:AnnotationProperty`
- Do NOT create individual instances
- Add rdfs:label and rdfs:comment annotations to every class and property
- Declare a mandatory ontology header

**Known assumptions and exclusions:**
- This ontology does not include specific vessel types or propulsion systems.
- This ontology does not include vessel location or trajectory data.
