**Turtle Ontology Design Pattern (ODP)**

```turtle
:Ontology a owl:Ontology ;
  rdfs:label "Maritime Vessel Ontology" ;
  rdfs:comment "A formalized and extensible conceptual model for representing ships and their properties in a machine-interpretable way.".

:Ship a owl:Class ;
  rdfs:label "Ship" ;
  rdfs:comment "Represents a maritime vessel.".

:VesselCharacteristics a owl:Class ;
  rdfs:label "VesselCharacteristics" ;
  rdfs:comment "Represents the characteristics of a ship.".

:TechnicalSpecifications a owl:Class ;
  rdfs:label "TechnicalSpecifications" ;
  rdfs:comment "Represents the technical specifications of a ship.".

:RegistryData a owl:Class ;
  rdfs:label "RegistryData" ;
  rdfs:comment "Represents registry data of a ship.".

:AISTracks a owl:Class ;
  rdfs:label "AISTracks" ;
  rdfs:comment "Represents AIS tracks of a ship.".

:hasVessel rdf:Property ;
  rdfs:domain :Ship ;
  rdfs:range :Ship ;
  rdfs:label "hasVessel" ;
  rdfs:comment "Relates a ship to its characteristics, technical specifications, registry data, AIS tracks, etc.".

:hasCharacteristics rdf:Property ;
  rdfs:domain :Ship ;
  rdfs:range :VesselCharacteristics ;
  rdfs:label "hasCharacteristics" ;
  rdfs:comment "Relates a ship to its characteristics.".

:hasTechnicalSpecifications rdf:Property ;
  rdfs:domain :Ship ;
  rdfs:range :TechnicalSpecifications ;
  rdfs:label "hasTechnicalSpecifications" ;
  rdfs:comment "Relates a ship to its technical specifications.".

:hasRegistryData rdf:Property ;
  rdfs:domain :Ship ;
  rdfs:range :RegistryData ;
  rdfs:label "hasRegistryData" ;
  rdfs:comment "Relates a ship to its registry data.".

:hasAISTracks rdf:Property ;
  rdfs:domain :Ship ;
  rdfs:range :AISTracks ;
  rdfs:label "hasAISTracks" ;
  rdfs:comment "Relates a ship to its AIS tracks.".

:PropulsionSystem a owl:Class ;
  rdfs:label "PropulsionSystem" ;
  rdfs:comment "Represents the propulsion system of a ship.".

:hasPropulsionSystem rdf:Property ;
  rdfs:domain :TechnicalSpecifications ;
  rdfs:range :PropulsionSystem ;
  rdfs:label "hasPropulsionSystem" ;
  rdfs:comment "Relates the technical specifications of a ship to its propulsion system.".

:DigitalTwin a owl:Class ;
  rdfs:label "DigitalTwin" ;
  rdfs:comment "Represents the digital twin of a ship.".

:isBasedOn rdf:Property ;
  rdfs:domain :DigitalTwin ;
  rdfs:range :Ship ;
  rdfs:label "isBasedOn" ;
  rdfs:comment "Relates a digital twin to the ship it represents.".
```

**Documentation**

- Intent: This pattern provides a formalized and extensible conceptual model for representing ships and their properties in a machine-interpretable way, supporting interoperability, reuse, and automated reasoning across various maritime domains.
- Covered requirements:
  - Fleet Management and Operational Planning: The ontology supports standardized and machine-readable descriptions of vessel characteristics.
  - Search and Rescue (SAR) Operations: The ontology enables fast semantic querying of relevant vessel trajectory data for time-critical emergency situations.
  - Semantic Data Integration, Search and Analysis: The ontology acts as a common semantic
