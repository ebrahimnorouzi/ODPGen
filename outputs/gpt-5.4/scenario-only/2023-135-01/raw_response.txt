  rdfs:comment "An ontology design pattern for modeling an author who adopts different names for publishing books, including name changes such as those occurring after marriage." .

  rdfs:comment "A person who authors books and may use different names over time or for publication." .

:Name a owl:Class ;
  rdfs:label "Name" ;

  rdfs:label "Name change" ;

:Name owl:disjointWith :NameChange .

  rdfs:label "has name" ;
  rdfs:comment "Relates an author to a name used by that author." ;
  rdfs:domain :Author ;
  rdfs:range :Name .

  rdfs:label "uses publication name" ;
  rdfs:comment "Relates an author to a name adopted for publishing books." ;
  rdfs:domain :Author ;
  rdfs:range :PublicationName ;

:authorsBook a owl:ObjectProperty ;
  rdfs:label "authors book" ;

  rdfs:label "has name change" ;
  rdfs:comment "Relates an author to a name change associated with that author." ;

  rdfs:range :NameChange .

:fromName a owl:ObjectProperty ;
  rdfs:label "from name" ;
  rdfs:comment "Relates a name change to the earlier name." ;
  rdfs:domain :NameChange ;

:toName a owl:ObjectProperty ;
  rdfs:label "to name" ;
  rdfs:comment "Relates a name change to the later name." ;
  rdfs:domain :NameChange ;
  rdfs:range :Name .

## Documentation

**Intent:**  
Model an author who may use different names for publishing books and may undergo name changes, such as after marriage.

**Covered requirements:**
- An author can have different names.
- Some names are specifically used as publication names.
- A book is authored by an author.
- A book can be published under a particular publication name.
- Name changes can be represented.
- A name change can capture an earlier name and a later name.
- Name changes may be associated with an author.

**Known assumptions and exclusions:**
- The pattern treats an author as a person implicitly, without introducing a separate `Person` class, to stay within scope.
- No temporal information is modeled for when a name was used or when a name change occurred.
- No specific reason for a name change is modeled; marriage is
