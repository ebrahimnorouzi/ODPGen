```turtle
@prefix owl:  <http://www.w3.org/2002/07/owl#> .
@prefix rdf:  <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .
@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#> .
@prefix xsd:  <http://www.w3.org/2001/XMLSchema#> .
@prefix :     <http://example.org/odp#> .

:Ontology a owl:Ontology ;
    rdfs:label "ODRL policy evaluation context pattern for partial video access and research purpose" ;
    rdfs:comment "An ontology design pattern for representing real-world information relevant to evaluating ODRL policies, specifically a request by an agent to access a segment of a video stream for an academic research project." .

:Agent a owl:Class ;
    rdfs:label "Agent" ;
    rdfs:comment "An entity that seeks or holds access to a resource." .

:Asset a owl:Class ;
    rdfs:label "Asset" ;
    rdfs:comment "A resource to which access may be requested or granted." .

:VideoStream a owl:Class ;
    rdfs:label "Video stream" ;
    rdfs:comment "A streaming video asset." ;
    rdfs:subClassOf :Asset .

:AccessRequest a owl:Class ;
    rdfs:label "Access request" ;
    rdfs:comment "A request by an agent to access an asset under certain constraints and for a stated purpose." .

:TemporalSegment a owl:Class ;
    rdfs:label "Temporal segment" ;
    rdfs:comment "A bounded segment of a media asset identified by a start and end time." .

:Purpose a owl:Class ;
    rdfs:label "Purpose" ;
    rdfs:comment "The intended purpose for which access is requested." .

:AcademicResearchProject a owl:Class ;
    rdfs:label "Academic research project" ;
    rdfs:comment "A purpose corresponding to an academic research project." ;
    rdfs:subClassOf :Purpose .

:Agent owl:disjointWith :Asset, :AccessRequest, :TemporalSegment, :Purpose .
:Asset owl:disjointWith :AccessRequest, :TemporalSegment, :Purpose .
:AccessRequest owl:disjointWith :TemporalSegment, :Purpose .
:TemporalSegment owl:disjointWith :Purpose .

:requestedBy a owl:ObjectProperty ;
    rdfs:label "requested by" ;
    rdfs:comment "Relates an access request to the agent making the request." ;
    rdfs:domain :AccessRequest ;
    rdfs:range :Agent .

:requestsAccessTo a owl:ObjectProperty ;
    rdfs:label "requests access to" ;
    rdfs:comment "Relates an access request to the asset for which access is sought." ;
    rdfs:domain :AccessRequest ;
    rdfs:range :Asset .

:hasRequestedSegment a owl:ObjectProperty ;
    rdfs:label "has requested segment" ;
    rdfs:comment "Relates an access request to the temporal segment of the asset that is needed." ;
    rdfs:domain :AccessRequest ;
    rdfs:range :TemporalSegment .

:hasPurpose a owl:ObjectProperty ;
    rdfs:label "has purpose" ;
    rdfs:comment "Relates an access request to the purpose for which access is sought." ;
    rdfs:domain :AccessRequest ;
    rdfs:range :Purpose .

:segmentStartMinute a owl:DatatypeProperty ;
    rdfs:label "segment start minute" ;
    rdfs:comment "The starting minute of a temporal segment within a media asset." ;
    rdfs:domain :TemporalSegment ;
    rdfs:range xsd:decimal .

:segmentEndMinute a owl:DatatypeProperty ;
    rdfs:label "segment end minute" ;
    rdfs:comment "The ending minute of a temporal segment within a media asset." ;
    rdfs:domain :TemporalSegment ;
    rdfs:range xsd:decimal .
```

**Intent:**  
Model the real-world context needed to evaluate an ODRL policy for a request to access a specific portion of a video stream for an academic research purpose.

**Covered requirements:**
- Represents an agent who wants access.
- Represents the requested asset as a video stream.
- Represents that only a specific temporal portion of the video stream is needed.
- Represents start and end minutes for the requested segment.
- Represents the purpose of access.
- Represents the purpose as an academic research project.
- Structures this information as context aiding ODRL policy evaluation.

**Known assumptions and exclusions:**
- The pattern models only evaluation-relevant context, not ODRL policy constructs themselves.
- “Bob” is not represented as an individual because only schema axioms were requested
