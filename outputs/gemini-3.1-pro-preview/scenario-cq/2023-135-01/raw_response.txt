```turtle
@prefix owl:  <http://www.w3.org/2002/07/owl#> .
@prefix rdf:  <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .
@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#> .
@prefix xsd:  <http://www.w3.org/2001/XMLSchema#> .
@prefix :     <http://example.org/odp#> .

:Ontology a owl:Ontology ;
    rdfs:label "Author Pseudonym and River Trajectory Ontology" ;
    rdfs:comment "An ontology design pattern representing authors, their pseudonyms, name changes, roles, as well as rivers and national parks to satisfy the provided scenario and competency questions." .

### Classes ###

:Author a owl:Class ;
    rdfs:label "Author" ;
    rdfs:comment "A person who writes and publishes books or other literary works." .

:Book a owl:Class ;
    rdfs:label "Book" ;
    rdfs:comment "A written work or publication created by an author." .

:PoemCollection a owl:Class ;
    rdfs:subClassOf :Book ;
    rdfs:label "Poem Collection" ;
    rdfs:comment "A specific type of book that contains a collection of poems." .

:Name a owl:Class ;
    rdfs:label "Name" ;
    rdfs:comment "An appellation or title used to identify a person." .

:Pseudonym a owl:Class ;
    rdfs:subClassOf :Name ;
    rdfs:label "Pseudonym" ;
    rdfs:comment "A fictitious name adopted by an author to publish works." .

:AlternativeName a owl:Class ;
    rdfs:subClassOf :Name ;
    rdfs:label "Alternative Name" ;
    rdfs:comment "An alternative appellation used by a person to assume a specific role." .

:Role a owl:Class ;
    rdfs:label "Role" ;
    rdfs:comment "A function or position assumed by a person, such as a book writer." .

:NameChangeEvent a owl:Class ;
    rdfs:label "Name Change Event" ;
    rdfs:comment "An event that results in a person adopting a new name." .

:Marriage a owl:Class ;
    rdfs:subClassOf :NameChangeEvent ;
    rdfs:label "Marriage" ;
    rdfs:comment "A specific life event that may result in a name change." .

:River a owl:Class ;
    rdfs:label "River" ;
    rdfs:comment "A natural flowing watercourse." .

:Trajectory a owl:Class ;
    rdfs:label "Trajectory" ;
    rdfs:comment "The path or course followed by a river." .

:NationalPark a owl:Class ;
    rdfs:label "National Park" ;
    rdfs:comment "A protected area of land designated by a national government." .

### Object Properties ###

:publishes a owl:ObjectProperty ;
    rdfs:domain :Author ;
    rdfs:range :Book ;
    rdfs:label "publishes" ;
    rdfs:comment "Relates an author to a book they have published." .

:usesName a owl:ObjectProperty ;
    rdfs:domain :Author ;
    rdfs:range :Name ;
    rdfs:label "uses name" ;
    rdfs:comment "Relates an author to a name they use or have used." .

:hasPseudonym a owl:ObjectProperty ;
    rdfs:subPropertyOf :usesName ;
    rdfs:domain :Author ;
    rdfs:range :Pseudonym ;
    rdfs:label "has pseudonym" ;
    rdfs:comment "Relates an author to a specific pseudonym they use." .

:hasAlternativeName a owl:ObjectProperty ;
    rdfs:subPropertyOf :usesName ;
    rdfs:domain :Author ;
    rdfs:range :AlternativeName ;
    rdfs:label "has alternative name" ;
    rdfs:comment "Relates an author to an alternative name they use." .

:publishedUnderName a owl:ObjectProperty ;
    rdfs:domain :Book ;
    rdfs:range :Name ;
    rdfs:label "published under name" ;
    rdfs:comment "Relates a book to the specific name (e.g., pseudonym) under which it was published." .

:assumesRole a owl:ObjectProperty ;
    rdfs:domain :Author ;
    rdfs:range :Role ;
    rdfs:label "assumes role" ;
    rdfs:comment "Relates an author to a role they have taken on." .

:acquiredThrough a owl:ObjectProperty ;
    rdfs:domain :Name ;
    rdfs:range :NameChangeEvent ;
    rdfs:label "acquired through" ;
    rdfs:comment "Relates a name to the event (like marriage) that caused it to be adopted." .

:hasTrajectory a owl:ObjectProperty ;
    rdfs:domain :River ;
    rdfs:range :Trajectory ;
    rdfs:label "has trajectory" ;
    rdfs:comment "Relates a river to its physical path or trajectory." .

:crosses a owl:ObjectProperty ;
    rdfs:domain :River ;
    rdfs:range :NationalPark ;
    rdfs:label "crosses" ;
    rdfs:comment "Relates a river to a national park that it flows through." .

### Datatype Properties ###

:nameString a owl:DatatypeProperty ;
    rdfs:domain :Name ;
    rdfs:range xsd:string ;
    rdfs:label "name string" ;
    rdfs:comment "The literal string value of a name." .

:title a owl:DatatypeProperty ;
    rdfs:domain :Book ;
    rdfs:range xsd:string ;
    rdfs:label "title" ;
    rdfs:comment "The literal string value of a book's title." .
```

### 2. Scenario-requirement-to-axiom mapping

*   **"An author adopting different names"**: Encoded using the `:Author` and `:Name` classes, connected by the `:usesName` object property.
*   **"to publish books"**: Encoded using the `:Book` class, the `:publishes` object property (Author to Book), and the `:publishedUnderName` object property (Book to Name) to capture the specific name used for a specific publication.
*   **"Name changes (e.g. - after marriage)"**: Encoded using the `:NameChangeEvent` class and its subclass `:Marriage`. The relationship between a new name and the event causing the change is captured by the `:acquiredThrough` object property.

### 3. CQ-to-axiom mapping

*   **CQ1: Under what pseudonym did the author C. S. Lewis published a collection of poems, Spirit in Bondage?**
    *   *Classes:* `:Author`, `:Pseudonym`, `:PoemCollection`
    *   *Properties:* `:publishes` (to link author to the collection), `:publishedUnderName` (to link the collection to the pseudonym), `:hasPseudonym` (to link the author to the pseudonym), `:title` (to query for "Spirit in Bondage"), `:nameString` (to query for "C. S. Lewis" and the resulting pseudonym).
*   **CQ2: What alternative did C. S. Lewis used to assume the role of a book writer?**
    *   *Classes:* `:Author`, `:AlternativeName`, `:Role`
    *   *Properties:* `:hasAlternativeName` (to link the author to the alternative name), `:assumesRole` (to link the author to the role), `:nameString` (to query for the author's name).
*   **CQ3: Show the trajectories of rivers which cross national parks?**
    *   *Classes:* `:River`, `:Trajectory`, `:NationalPark`
    *   *Properties:* `:hasTrajectory` (to link the river to its trajectory), `:crosses` (to link the river to the national park).

### 4. Intentionally excluded concepts

*   **Specific Individuals (C. S. Lewis, Spirit in Bondage):** Excluded because the prompt strictly requires schema axioms only (no individual instances). These would be modeled as instances of `:Author` and `:PoemCollection` respectively.
*   **"Book Writer" as a distinct class:** Excluded because it is more accurately modeled as an instance of the `:Role` class (e.g., `:BookWriterRole a :Role`). Creating a specific class for every possible role would clutter the schema unnecessarily.
*   **Geospatial Coordinates:** Excluded for the river trajectories. While a real-world application might use complex geometries (like GeoSPARQL) to map a trajectory, the CQ only asks to "show the trajectories", which is structurally satisfied by the `:Trajectory` class and `:hasTrajectory` property without over-engineering unrequested spatial datatypes.
