Intent:
The ontology models the relationships between software components, their requirements, and hardware resources, in order to match the requirements with the appropriate hardware resources.

Covered requirements:

* The ontology should include classes for software, requirements, hardware, and matches.
* The ontology should include properties for the relationships between software and requirements, requirements and values, hardware and characteristics, and matches and candidates.
* The ontology should include axioms for the domain and range of each property.
* The ontology should include annotations for each class and property.

Known assumptions and exclusions:

* The ontology assumes that software components have specific requirements that can be matched with hardware resources.
* The ontology assumes that hardware resources have specific characteristics that can be matched with software requirements.
* The ontology does not include any specific instances of software or hardware resources.
* The ontology does not include any relationships between software components or hardware resources other than the match relationship.
