```turtle

:Ontology a owl:Ontology ;
  rdfs:label "Climate dataset publication pattern" ;
  rdfs:comment "An ontology design pattern for describing the publication of a climate dataset consisting of average daily maximum near-surface air temperature values for a whole region over a given year, derived from some process, with one independent variable (time) and one dependent variable." .

:Dataset a owl:Class ;
  rdfs:label "Dataset" ;
  rdfs:comment "A published dataset." .

  rdfs:label "Climate dataset" ;

  rdfs:subClassOf :Dataset .

  rdfs:comment "The publication of a dataset." .

:Variable a owl:Class ;
  rdfs:label "Variable" ;
  rdfs:comment "A variable represented in a dataset." .

:IndependentVariable a owl:Class ;
  rdfs:label "Independent variable" ;
  rdfs:comment "A variable that serves as an independent variable in a dataset." ;
  rdfs:subClassOf :Variable .

:DependentVariable a owl:Class ;
  rdfs:label "Dependent variable" ;
  rdfs:comment "A variable that serves as a dependent variable in a dataset." ;
  rdfs:subClassOf :Variable ;
  owl:disjointWith :IndependentVariable .

:TimeVariable a owl:Class ;
  rdfs:label "Time variable" ;
  rdfs:comment "An independent variable representing time." ;
  rdfs:subClassOf :IndependentVariable .

:TemperatureVariable a owl:Class ;
  rdfs:label "Temperature variable" ;
  rdfs:comment "A dependent variable representing temperature." ;
  rdfs:subClassOf :DependentVariable .

:NearSurfaceAirTemperatureVariable a owl:Class ;
  rdfs:label "Near-surface air temperature variable" ;
  rdfs:comment "A temperature variable representing near-surface air temperature." ;
  rdfs:subClassOf :TemperatureVariable .

:DailyMaximumNearSurfaceAirTemperatureVariable a owl:Class ;
  rdfs:label "Daily maximum near-surface air temperature variable" ;
  rdfs:comment "A near-surface air temperature variable representing daily maximum values." ;
  rdfs:subClassOf :NearSurfaceAirTemperatureVariable .

:SpatialExtent a owl:Class ;
  rdfs:label "Spatial extent" ;
  rdfs:comment "A geographic area over which a dataset is defined." .

:TemporalExtent a owl:Class ;
  rdfs:label "Temporal extent" ;
  rdfs:comment "A time interval over which a dataset is defined." .

:RegionalAggregateDataset a owl:Class ;
  rdfs:label "Regional aggregate dataset" ;
  rdfs:comment "A dataset providing values aggregated for a whole region rather than for a spatial grid." ;
  rdfs:subClassOf :ClimateDataset .

  rdfs:domain :Dataset ;

  rdfs:domain :Dataset ;
  rdfs:range xsd:string .

  rdfs:domain :Dataset ;
  rdfs:range xsd:nonNegativeInteger .

:hasYear a owl:DatatypeProperty ;
  rdfs:label "has year" ;

  rdfs:domain :TemporalExtent ;
  rdfs:range xsd:gYear .

  [ a owl:Restriction ;
    owl:onProperty :hasDependentVariable ;
    owl:qualifiedCardinality "1"^^xsd:nonNegativeInteger ;
    owl:onClass :DependentVariable
  ] ,
  [ a owl:Restriction ;
    owl:onProperty :hasSpatialExtent ;
    owl:qualifiedCardinality "1"^^xsd:nonNegativeInteger ;
    owl:onClass :SpatialExtent
  ] ,
  [ a owl:Restriction ;
    owl:onProperty :hasTemporalExtent ;
    owl:qualifiedCardinality "1"^^xsd:nonNegativeInteger ;
    owl:onClass :TemporalExtent
  ] ,
  [ a owl:Restriction ;
    owl:onProperty :hasValueCountPerTimeStep ;
    owl:hasValue "1"^^xsd:nonNegativeInteger
  ] .
```

**Intent:** Model the publication of a climate dataset that provides one daily aggregated temperature value for a whole region over a year, derived from some process, with one independent variable and one dependent variable.

**Covered requirements:**
- Models a dataset publication.
- Models a climate dataset in the climate services domain.
- Captures derivation from some process.
- Represents a dataset of average daily maximum near-surface air temperature.
- Represents coverage over the whole of a region rather than a spatial grid.
- Represents coverage over a year.
- Constrains the dataset to one independent variable.
- Constrains the dataset to one dependent variable.
- Constrains the dataset to one value per time step.

**Known assumptions and exclusions:**
- “Italy” and “2024” are not instantiated, since only schema axioms were requested; they are represented generically via spatial and temporal extent classes and datatype properties.
- The pattern does not distinguish among specific derivation subtypes such as observation, simulation, or aggregation beyond the generic derivation process class.
- “Average” is reflected only in the overall scenario comment and not modeled as a separate concept, to avoid adding structure not strictly required by the scenario.
- No units, encoding formats, publishers, or distribution metadata are included because they are not explicitly required by the scenario.
